# Capstone_1: Business Analysis with SQL and Excel

## Project Overview

This project focuses on analyzing sales data for EmporiUm, a fictional student bookstore chain that also sells technology products, art supplies, and other merchandise both in-store and online.

The goal is to explore and analyze sales data to answer business questions related to my assigned sales territory (**New York (NY)**), and extract useful insights to support business decisions.

## Tools Used

- **MySQL:** To query, retrieve, and analyze data.
- **Excel:** To create a PivotChart and visualize sales data.

## Repository Contents

- `.sql` script containing the queries used to answer the sales manager's questions.
- `.csv` file containing the exported data used for the PivotChart.
- Excel file containing the PivotChart.
- Project documentation and presentation materials.
